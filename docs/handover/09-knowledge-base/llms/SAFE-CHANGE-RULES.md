## Need explicit approval

- Breaking content-model changes; removing fields; renaming persisted fields
- Changing URLs or routes; taxonomy IDs; analytics schemas
- Changing shared decorators used by several blocks
- Deleting or unpublishing AEM content; changing production configuration; security or permissions; integrations

## Always

- Lint and tests; generated files current; feature preview; documentation updated.
