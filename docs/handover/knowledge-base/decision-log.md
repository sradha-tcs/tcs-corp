## How to Use This Log

- **Status:** Approved (implemented and recorded), Proposed (open, not implemented), Superseded (replaced by a later entry, named in the row). Entries derived by the knowledge base authors, not decided by the project, are listed separately under [Recommendations (not approved)](#recommendations-not-approved).
- **Date:** the date of the handover revision or the merge date of the pull request that recorded the decision; "Not recorded" when the source has none.
- **References:** "rev 2.xx" is a row of the handover's Revision History, "F-xx" a finding and "O-xx" an open item of its Part 16, "PR #nn" a merged pull request of `sradha-tcs/tcs-corp`.
- **Adding a decision:** append the next id (`KB-D-0nn`), status Proposed until the user approves it; when it replaces an entry, set the old one to Superseded and name the new id. Never rewrite an Approved entry's history.
