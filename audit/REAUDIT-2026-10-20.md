# Block ecosystem re-audit (20 October 2026)

A second, fresh audit of the whole block ecosystem, on the code after the first audit (PR #118) and the built-in Columns / Button change (PR #119). Same method as the first audit ([BLOCK-ECOSYSTEM-AUDIT.md](BLOCK-ECOSYSTEM-AUDIT.md)): a generated inventory (62 components, 926 dialog fields; after the fixes 62 and 924), four new code reviews of every block ([reaudit/](reaudit/), file:line evidence), every library and curated page at 5 widths with axe and data-layer checks, and the published site (aem.page: the current code on the content installed before, package 1.0.6) to check that content authored before still works.

## 1. Result

- **First audit re-verified:** most corrections confirmed by the four reviews; not fixed or regressed: D-A-10 (deferral premise wrong), D-A-19 (List), D-B-4 (Hero), D-B-16 (dark Hero eyebrow), D-C-13, D-C-17 (regression), D-D-25 (live logo). All now corrected (section 3).
- **New defects:** 46 (33 minor, 9 major, 2 trivial, 2 low): 40 corrected, 2 content action, 2 deferred, 1 operations, 1 blocked.
- **Content authored before (aem.page, current code):** forms (with the real "name, field-text" rows), tables (tab rows), Tabs Containers holding built-in Columns, Columns blocks, Heroes and Table Lists with Motion Type, Canvas buttons with linkType, built-in Buttons with View / Icon, the Teaser with the removed Personalization option and Page Header CTAs with an empty style all render; videos authored with the former poster fields have no poster (the field was never delivered: R-D-7, content migration).
